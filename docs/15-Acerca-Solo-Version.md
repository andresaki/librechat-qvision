# Modal «Acerca de» — solo versión

## Comportamiento

La sección «Acerca de» del modal de configuración muestra únicamente la fila de versión. Se
mantiene el bloque de soporte que permite copiar los diagnósticos de compilación.

## Validación

1. Abrir Configuración.
2. Ir a «Acerca de».
3. Confirmar que solo aparece la fila «Versión».
4. Confirmar que siguen visibles el texto de soporte y el botón «Copiar diagnóstico».
